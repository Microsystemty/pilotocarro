# AutoShowcase Hub

Crie a base de um sistema moderno para uma loja de veículos.

O sistema deve ter:

Página inicial com banner principal, veículos em destaque e botão de WhatsApp.

Página de estoque com cards dos veículos.

Filtros básicos por marca, modelo, ano e faixa de preço.

Página individual do veículo com galeria de fotos, preço, ano, quilometragem, câmbio, combustível, descrição e botão de contato pelo WhatsApp.

Página “Venda seu carro”.

Página “Financiamento”.

Página de contato.

Layout totalmente responsivo para computador e celular.

Crie também uma estrutura inicial de painel administrativo para futuramente cadastrar, editar e excluir veículos.

Use um design moderno, profissional e clean, inspirado em sites de revendas de veículos premium, mas sem copiar nenhum site existente.

Organize bem os componentes e o código para que o projeto possa ser continuado posteriormente através do GitHub.

Por enquanto, priorize a estrutura visual, navegação e organização do projeto. Não implemente funcionalidades complexas que consumam muitos recursos.

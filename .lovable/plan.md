# Plano

Criar a base visual e navegável de um sistema moderno para uma loja de veículos, com foco em estrutura, organização e continuidade futura.

## O que será construído

- Página inicial com banner principal, veículos em destaque e botão de WhatsApp.
- Página de estoque com cards de veículos e filtros visuais por marca, modelo, ano e faixa de preço.
- Página individual de veículo com galeria, preço, ano, quilometragem, câmbio, combustível, descrição e contato por WhatsApp.
- Páginas “Venda seu carro”, “Financiamento” e “Contato”.
- Estrutura inicial de painel administrativo para futuramente cadastrar, editar e excluir veículos.
- Layout responsivo para computador e celular.
- Design premium, moderno, profissional e clean, sem copiar sites existentes.

## Organização do projeto

- Criar componentes reutilizáveis para cabeçalho, rodapé, cards, filtros, botões de WhatsApp e seções compartilhadas.
- Centralizar dados iniciais dos veículos em um arquivo reutilizável, sem banco de dados por enquanto.
- Criar rotas separadas para cada página principal, mantendo navegação clara e preparada para evolução.
- Ajustar o sistema visual global com tokens de cores, fontes, sombras e superfícies consistentes.

## Detalhes técnicos

- Usar as rotas do TanStack Start já existentes no projeto.
- Usar navegação interna com links tipados.
- Definir metadados próprios para cada página.
- Manter os filtros como estrutura visual/local, sem funcionalidades complexas ou consumo de recursos.
- Preparar o painel administrativo como interface inicial estática, sem autenticação ou persistência nesta etapa.
